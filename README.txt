NUMBER MERGE — WEBSITE LAUNCH

1. Create a NEW public repository on GitHub, e.g. number-merge-game.
2. Upload the contents of this folder to the repository root (index.html, manifest.webmanifest, sw.js, privacy.html and both icons). Do not upload the ZIP itself.
3. Go to Settings > Pages > Build and deployment > Source: Deploy from a branch.
4. Select branch main and folder / (root), then Save.
5. Wait for the GitHub Pages link to appear. It will usually resemble https://YOUR-USERNAME.github.io/number-merge-game/
6. Open the link on your phone, play several moves, refresh, and check that your score is saved.

This package does NOT contain real ads, online leaderboards or payment integration. Those require additional development and service setup.

To update: replace index.html and other modified files, then commit changes.
