Number Merge — Privacy

This version runs in your browser. Your game board, score and best score are stored locally on your device using browser storage. The game does not require an account and does not send gameplay data to our own server.

The website hosting provider may process standard technical connection information, such as IP addresses, to deliver the site. This release contains no advertising or analytics SDK.

Clearing site data may delete saved game progress. You can stop using the game at any time.

This statement applies only to the initial web release. It must be updated before adding advertising, analytics, accounts, or other services.
